## Research Projects

### 1. Hyperspectral Image Segmentation

Semantic segmentation of EnMAP hyperspectral imagery using three deep learning architectures: U-Net, U-Net++ and Atrous U-Net.

The research involved comparing neural network architectures and spectral dimensionality reduction techniques for agricultural crop classification.

**Key topics:** Hyperspectral Remote Sensing, Deep Learning, Semantic Segmentation, Spectral Band Selection, U-Net Architectures.

**[Scientific Publication](https://doi.org/10.3390/a18090588)**

### 2. Crop Yield Prediction Using Sentinel-2

Machine learning-based crop yield estimation using multi-temporal Sentinel-2 imagery, regression algorithms and SHAP explainability.

The research investigated spectral and temporal predictors of agricultural productivity using satellite observations.

**Key topics:** Agricultural Remote Sensing, Regression, Machine Learning, Explainable AI, Sentinel-2.

**[Scientific Publication](https://doi.org/10.3390/a19050392)**

### 3. Land Cover Classification and Spatial Transferability

Deep learning-based land cover classification using multi-seasonal Sentinel-2 imagery.

Four architectures were evaluated: CNN, U-Net++, ConvNeXt and Vision Transformer (ViT), with emphasis on spatial cross-validation and generalization between geographical regions.

**Key topics:** Deep Learning, Land Cover Classification, Spatial Cross-Validation, CNNs, ConvNeXt, Vision Transformers, Transferability.

**[Scientific Publication](https://doi.org/10.3390/rs18152463)**

**[Explore Python Deep Learning Code](./LandCover-DeepLearning/)**
