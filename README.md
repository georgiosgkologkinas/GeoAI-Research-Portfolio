## Research Projects

### 1. Hyperspectral Image Segmentation

Semantic segmentation of EnMAP hyperspectral imagery using three deep learning architectures: U-Net, U-Net++ and Atrous U-Net. The research involved comparing different neural network architectures for land cover mapping from hyperspectral satellite data.

**Key topics:** Hyperspectral Remote Sensing, Deep Learning, Semantic Segmentation, U-Net, U-Net++, Atrous Convolutions.

### 2. Crop Yield Prediction Using Sentinel-2

Machine learning-based crop yield estimation using multispectral satellite data, Random Forest, Support Vector Regression and SHAP explainability.

**Key topics:** Agricultural Remote Sensing, Machine Learning, Regression, Explainable AI.

### 3. Land Cover Classification and Spatial Transferability

Deep learning-based land cover mapping using Sentinel-2 imagery, with a focus on spatial generalization between geographic regions.

**Key topics:** Land Cover Classification, CNNs, U-Net++, ConvNeXt, Vision Transformers, Spatial Transferability.

### 4. Undergraduate Thesis — Statistical Analysis Using R

Undergraduate thesis conducted as part of my studies in Surveying and Geoinformatics Engineering, involving statistical analysis using the R programming language.

This project represents part of my academic foundation in statistical computing and data analysis, complementing my subsequent work in Machine Learning, Deep Learning and GeoAI.

**Key topics:** R Programming, Statistical Analysis, Statistical Computing.

## Current Research

My doctoral research investigates the integration of Earth Observation, meteorological and geospatial data with machine learning for environmental modelling and air quality forecasting.

A particular focus is placed on spatial generalization, multimodal data fusion and the transferability of predictive models to previously unseen geographical areas.
